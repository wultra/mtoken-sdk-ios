# Migration from 3.1.x to 3.2.x

Version `3.2.x` updates the underlying security and networking libraries:

| Dependency | 3.1.x | 3.2.x |
|---|---:|---:|
| `PowerAuth2` | `2.0.x` | `2.1.x` |
| `WultraPowerAuthNetworking` | `2.1.x` | `3.0.x` |

The minimum supported deployment target is now **iOS 15.0**. Update your application's deployment target before upgrading. No Mobile Token SDK API changes are required for this migration.
